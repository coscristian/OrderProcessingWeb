# Order Processing UI

Angular frontend for the Order Processing API.

## Requirements

- Node.js
- npm
- Angular CLI

## Installation

From the Angular project directory:

```bash
npm install
```

Make sure the API is running before starting the frontend.

## Run the Application

Start the development server with:

```bash
ng serve
```

The application will be available at:

```text
http://localhost:4200
```

The frontend uses the Order Processing API running at:

```text
http://localhost:8080
```
